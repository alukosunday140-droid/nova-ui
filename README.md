# 🚀 Nova UI

[![CI](https://github.com/yourusername/nova-ui/actions/workflows/ci.yml/badge.svg)](https://github.com/yourusername/nova-ui/actions/workflows/ci.yml)
[![npm version](https://badge.fury.io/js/@yourusername%2Fnova-ui.svg)](https://www.npmjs.com/package/@yourusername/nova-ui)

A modern, accessible, and production-ready React UI component library built with TypeScript and Tailwind CSS.

## ✨ Features

- 🎨 **Beautiful by default** — Carefully crafted components with sensible defaults
- ♿ **Accessible** — Built with accessibility in mind
- 🔧 **Type-safe** — Full TypeScript support
- 🎭 **Customizable** — Easy to theme with Tailwind CSS
- 📦 **Tree-shakeable** — Only import what you need
- 🧪 **Well tested** — Comprehensive test coverage with Vitest
- 📚 **Documented** — Interactive documentation with Storybook

## 📦 Installation

```bash
npm install @yourusername/nova-ui
```

## 🚀 Usage

```tsx
import { Button } from '@yourusername/nova-ui';
import '@yourusername/nova-ui/style.css';

function App() {
  return (
    <Button variant="primary" size="md">
      Get Started
    </Button>
  );
}
```
